# Upgrade guide for Grid v7.2.2

## Deprecated `DomSync.removeChild()` in favor of `DomSync.remove()`

The static method `DomSync.removeChild(parentElement, childElement)` is now deprecated. Use
`DomSync.remove(childElement)` instead, which derives the parent automatically and works correctly for descendant
elements (not just direct children).

**Old code**

```javascript
DomSync.removeChild(parentElement, childElement);
```

**New code**

```javascript
DomSync.remove(childElement);
```
