# Upgrade guide for Grid v7.0.1

## Deprecated the event property of Button click and action events

The `event` property of `Button`'s `click` and `action` events has been deprecated and replaced by the `domEvent`
property to better align with naming elsewhere (reducing risk of confusion with Bryntum event objects and Bryntum 
Scheduler events). It will be removed in a future major release. Replace any usage of it as shown below:

**Old code**

```javascript
button.on('click', ({ event }) => {
    // do something with event
});
```

**New code**

```javascript
button.on('click', ({ domEvent }) => {
    // do something with domEvent
});
```
