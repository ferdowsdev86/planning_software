# Upgrade guide for Grid v7.1.0

## Salesforce support

In the 7.0.0 release, we introduced significant changes to themes and styles. The previous `grid.stockholm.css` file has
been replaced with two separate CSS imports: `grid.css` and `theme-name.css`. Please update your application code
accordingly to ensure compatibility.

Additionally, we fixed several bugs that were identified after the major release. Version 7.1.0 is the first version in
the 7.x release cycle that is fully functional in Salesforce environments.
