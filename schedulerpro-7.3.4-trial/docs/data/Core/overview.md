# Bryntum Core

## What is Bryntum Core?

A versatile, high-performance data Bryntum Core components with vanilla JavaScript.

If you've purchased the licensed version, you can log in to the Bryntum Customer Zone to download Bryntum Core, or
access it directly through npm. The licensed distribution allows you to import only the classes you need directly from
the source files, reducing the Core's bundle size.
