# What's new in Scheduler Pro v7.2.0

## AI feature

A new AI feature has been added to the SchedulerPro. It provides a chat panel that lets users communicate with an AI 
agent that can help them interact with the SchedulerPro in different ways. For example, the user can ask the agent to 
filter the data, sort it, or select specific records. The agent can also perform data manipulation operations such as 
adding, updating, deleting records.

The feature is built to be LLM-agnostic, so it can be used with any LLM that supports tool calling.

To try it out and see an example of how to implement it, please check out our new
[AI demo](https://bryntum.com/products/schedulerpro/examples/ai-skillmatching/).

Please note that this feature is currently in an **experimental** stage and is subject to change in future releases.
